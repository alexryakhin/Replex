새로운 기능

Replex의 모든 업데이트를 최신순으로 소개합니다.

Replex 5.0

2026년 10월 · 버전 5.0

Replex 5.0은 앱의 모습과 사용감을 완전히 새로 만든 버전입니다. 주제는 Chalk & Iron. 그라파이트 캔버스에 선명한 강조 색상 하나, 전광판 같은 숫자, 그리고 세션이 단련하는 근육을 알려 주는 색상. Apple Watch 앱도 새롭게 디자인했고, AI 코치는 이제 프로그램 전체를 계획합니다.

새로운 디자인

  • 오늘, 플랜, 진행 상황, 코치, 프로필을 새롭게 디자인. 근육 그룹별 색상과 한눈에 들어오는 큰 숫자
  • 일러스트가 들어간 운동과 새로워진 근육 지도
  • 화면 모드 설정(시스템, 라이트, 다크)과 세 가지 강조 색상(Volt, 블루, 핑크), 그리고 어울리는 앱 아이콘
  • 새로운 실행 화면과 온보딩

Apple Watch

  • 새롭게 디자인한 Watch 앱: Digital Crown으로 무게와 횟수를 맞추고 ‘기록’ 탭
  • −15 / +15와 건너뛰기가 있는 휴식 카운트다운 링, 실시간 심박수, 심박 구간, 칼로리
  • 강조 색상이 Watch에도 적용

기록과 진행 상황

  • 맨몸 운동을 ‘맨몸’ 또는 ‘맨몸 + 10 kg’으로 표시하고, 건강 앱의 체중이나 직접 입력한 체중으로 볼륨에 포함
  • 운동 중 화면 켜 두기(프로필 › 환경설정)
  • 더 명확해진 진행 상황 그래프와 신기록, 숫자는 사용 언어의 표기로 표시

AI 코치 (Pro)

  • 매주 반복되는 여러 주짜리 프로그램을 원하는 날짜부터 계획
  • 세션 이동과 교체를 한 번의 확인으로 처리하고, 캘린더 일정 충돌도 확인
  • 보유한 장비와 단련하고 싶은 근육에 맞춰 운동 선택
  • 지난 날짜에 세션을 추가하거나 캘린더에 이미 있는 세션을 중복으로 넣지 않음

전반

  • 아랍어와 히브리어 지원 개선: 화살표와 레이아웃 좌우 반전, 일관된 숫자 표기
  • Watch 동기화와 실행에 관한 다수의 안정성 개선

Replex 4.1

2026년 9월 · 버전 4.1

Replex 4.1은 더 빠른 기록과 어디서 운동했는지를 더 명확하게 보여 주는 데 집중했습니다. 야외 운동 개선, 더 나아진 공유, 분석 기능 다듬기도 함께 담았습니다.

운동 지도

  • 모든 운동을 열면 러닝, 라이딩, 헬스장 세션을 지도에서 볼 수 있습니다
  • 축소하면 핀이 묶이고, 확대하면 활동별로 나뉩니다

더 빠른 기록

  • 운동 중 iPhone에서 세트를 바로 편집
  • Apple Watch에서 한 번의 탭으로 세트 기록
  • 한 주를 짤 때 더 매끄러운 계획 흐름

야외 운동과 건강

  • 가져온 야외 활동의 경로를 전체 화면으로 보기
  • 날짜와 시간은 운동을 기록한 곳의 시간대를 따름
  • 설정에서 기간을 지정해 건강 앱 운동을 더 쉽게 다시 가져오기

공유, 코치, 다듬기

  • 운동 공유 카드와 공유 편집 화면을 새롭게 디자인
  • 더 깔끔해진 코치의 빈 화면과 새로워진 앱 정보 화면
  • 더 부드러운 유산소 그래프 탐색과 더 선명한 심박수 선택선
  • 운동 기록이 많아도 모든 운동 화면이 빠르게 반응

Replex 4.0

2026년 8월 · 버전 4.0.0

Replex 4.0의 중심은 AI 코치입니다. 답하기 전에 실제 운동, 템플릿, 캘린더를 읽는 Pro 기능으로, 변경을 제안하고 무엇을 저장할지는 사용자가 결정합니다.

AI 코치 (Pro)

  • 운동 기록, 목표, 일정에 대해 자연스럽게 대화
  • 대화로 운동 템플릿 만들기와 편집
  • 근력 세션과 앞으로의 유산소 운동을 하나의 계획으로 일정에 추가
  • 모든 제안을 미리 보기. 캘린더 일정과 템플릿 편집은 적용을 탭해야만 반영됩니다
  • 상세 화면에서 특정 운동이나 가져온 러닝에 대해 질문
  • 연결이 끊겨도 복구되는 이어지는 대화

AI 코치를 쓰려면 Replex Pro 구독이 필요합니다. 코치 데이터 처리 방식은 개인정보 처리방침을 참고하세요.

iPhone으로 운동

  • Apple Watch가 없을 때도 iPhone으로 근력 운동 기록
  • 실시간 현황이 잠금 화면에 세션을 표시
  • Siri: 목소리로 운동 시작

분석과 건강

  • 분석 기간에 맞춘 러닝과 걷기 거리 그래프
  • 완료한 운동의 인터랙티브 심박수 그래프
  • 건강 앱에서 야외 활동을 경로 지도와 함께 가져오기
  • 새 야외 러닝과 라이딩을 가져오면 알림

Apple Watch와 안정성

  • 작은 Watch 화면에서도 깔끔한 지표와 휴식 타이머
  • 더 안정적인 Watch 실행과 iPhone 미러 동기화
  • 실시간 현황과 운동 화면 다듬기
  • 더 빠른 앱 실행과 HealthKit 가져오기 성능

캘린더와 계획

  • 근력 템플릿과 함께 앞으로의 유산소 운동을 일정에 추가
  • 캘린더 목록에 근력과 유산소 세션 아이콘
  • 운동 공유 카드와 계획 기능 개선
